# P2P Chat Secure — par HackestChad

## Fonctionnalités

- Connexion directe P2P via IP publique/privée et port configurables.
- Interface stylisée verte/rouge/noire.
- Profil utilisateur avec photo de profil (upload).
- Liste de contacts/amis.
- Historique des conversations chiffré.
- Transfert de fichiers entre pairs.
- Notifications, sonnerie, états "en ligne" / "écrit...".
- Chiffrement AES-256-GCM.

## Installation

```bash
pip install -r requirements.txt
python p2p_chat.py
```

## Utilisation

1. Lancer le script sur chaque machine.
2. Choisir un pseudo, ajouter une photo de profil.
3. Renseigner son IP publique (ex: affichée en haut) et le port d'écoute.
4. Ajouter un ami via son IP:port et cliquer "Connecter".
5. Envoyer des messages, fichiers et profils.
